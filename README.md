# 장고샘 바이브코딩 AI 선생님

초등학교 5학년 학생이 로그인 없이 사용하는 교육용 바이브코딩 웹앱입니다.

## 실행
1. Node.js 18 이상 설치
2. `npm install`
3. `.env.example`을 복사해 `.env` 생성
4. `.env`의 GEMINI_API_KEY에 실제 키 입력
5. `npm start`
6. http://localhost:3000

## 보안
실제 API 키는 GitHub에 올리지 마세요. Render 같은 호스팅 서비스의 환경변수에 넣으세요.
학생은 로그인 없이 사용할 수 있습니다.
